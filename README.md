## Packet Tracer Project

### Small Office Network

This project was created using Cisco Packet Tracer.

#### Network Devices
- 1 Router
- 1 Switch
- 3 PCs

#### IP Addressing

| Device | IP Address |
|---|---|
| Router G0/0 | 192.168.10.1 |
| PC1 | 192.168.10.10 |
| PC2 | 192.168.10.11 |
| PC3 | 192.168.10.12 |

Subnet Mask: `255.255.255.0`

Default Gateway: `192.168.10.1`

#### Connectivity Testing

PC1 was used to test connectivity to the router, PC2 and PC3 using the `ping` command.

- PC1 → Router ✅
- PC1 → PC2 ✅
- PC1 → PC3 ✅

#### Packet Tracer File
